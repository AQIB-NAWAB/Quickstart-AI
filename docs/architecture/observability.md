# Observability

Services export traces and metrics over OTLP HTTP to the collector. Locally, start the collector and Prometheus with `docker compose --profile observability up -d otel-collector prometheus`; Prometheus is available at `http://127.0.0.1:9090`. Services started on the host use `OTEL_EXPORTER_OTLP_ENDPOINT=http://127.0.0.1:4318` by default. The collector's metrics endpoint is private to the Compose network. Restart services after changing instrumentation. The local setup has no Alertmanager or paging receiver.

## Signals and charts

| Question                                   | PromQL                                                                                                                                                                                               | Meaning                                                                                     |
| ------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| Are requests failing?                      | `sum(rate(quickstart_http_requests_total{service_name="service-gateway",status_class="5xx"}[5m])) / clamp_min(sum(rate(quickstart_http_requests_total{service_name="service-gateway"}[5m])), 0.001)` | Gateway 5xx fraction; graph alongside traffic volume.                                       |
| Are requests slow?                         | `histogram_quantile(0.95, sum by (le) (rate(quickstart_http_duration_seconds_bucket{service_name="service-gateway"}[5m])))`                                                                          | Gateway p95 request duration in seconds.                                                    |
| Are requests being throttled?              | `sum(rate(quickstart_http_rate_limited_total{service_name="service-gateway"}[5m]))`                                                                                                                  | Gateway 429 responses per second.                                                           |
| Are agents being published?                | `sum(rate(quickstart_agent_published_total[5m]))`                                                                                                                                                    | Successful publish operations per second.                                                   |
| Is Redis failing closed?                   | `sum(rate(quickstart_gateway_redis_fail_closed_total[5m]))`                                                                                                                                          | Gateway rate-limit store failures per second.                                               |
| Are model calls timing out?                | `sum(rate(quickstart_model_timeout_total[5m]))`                                                                                                                                                      | Timed-out provider attempts per second, including retries.                                  |
| Is the evaluation database pool saturated? | `max(quickstart_db_pool_waiting{pool="eval"})`                                                                                                                                                       | Requests waiting to acquire a connection. A nonzero value sustained for two minutes alerts. |

HTTP measurements exclude health checks and count completed responses. Counters reset on process restart; use `rate` and aggregate across instances, not raw values as billing totals. The collector exports resource labels including `service_name` and a per-process `service_instance_id`, so simultaneous service replicas do not overwrite one another. HTTP labels are restricted to a fixed method set and status class. Request IDs, workspace IDs, user IDs, URLs, model names, and exception text never become metric labels. Traces and structured logs retain `request_id` for diagnosis; request logs omit raw paths and the error log does not include arbitrary exception text.

Alert expressions, thresholds, and durations are in [alerts.yml](../../infra/local/alerts.yml). Prometheus evaluates these locally but cannot page until a receiver is configured. Low-volume gateway traffic is excluded from the error-rate alert; tune thresholds and routing for the deployment.

Other services' worker and database pool saturation are not instrumented yet. The collector's local configuration is not a production high-availability or durable metrics deployment.
